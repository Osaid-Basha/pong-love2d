## Game Description

This is a simple Pong game made with Lua and Love2D. Two players move paddles to hit a ball. The ball bounces from the top and bottom walls and from the paddles.

## How to Run

Open a terminal in this project folder and run `love .`.

## Game Controls

- Left paddle: W to move up, S to move down.
- Right paddle: Up arrow to move up, Down arrow to move down.
